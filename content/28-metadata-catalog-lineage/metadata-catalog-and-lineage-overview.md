# Metadata Catalog and Lineage Overview

Metadata catalog technical/business contextet, ownershipet, classifications, qualityt, lifecycle-t és lineage-t tesz discoverable-vé. Catalog coverage, freshness, identity és stewardship nélkül a „cataloged” állítás csak részleges inventory.
