Sorrend: metadata concepts → catalog identity/ownership → OpenLineage provenance → quality/classification → glossary/domain/stewardship → ADR/governance → metadata exercise/case/reference.

Exit criteria: stable identity, lineage freshness, owner coverage, access/classification, lifecycle, decision rights és audit evidence.
