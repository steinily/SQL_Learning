# Project Governance and Metrics

Metrics are generated from manifest, metadata and validation artifacts. They are never manually edited as authoritative state.

## Required views

- Content Progress
- Verification Progress
- Release Readiness
- P0/P1/P2 coverage
- Domain coverage
- QA issue counts by severity
- Source health
- Execution-test coverage by engine
- Metadata quality
- Link health
- Knowledge-graph health
- Freshness/revalidation status
- Knowledge Debt
- Technical Debt

## Scope denominators

Report Baseline Scope, Current Scope and Discovered/Backlog separately.

## Release readiness

Release readiness is a deterministic gate, not an AI judgment and not a single health score.

Generated outputs will include PROJECT_STATUS.md and machine-readable metrics.
