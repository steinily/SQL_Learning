# Záróprojekt előkészítő feladat

Válassz egy domaint, és készíts hozzá legalább négy táblát. Írd le minden táblánál a grain-t, az elsődleges kulcsot, a külső kulcsokat és két üzleti megszorítást. Ezután készíts öt lekérdezést: egyszerű lista, JOIN, aggregáció/HAVING, al-lekérdezés vagy CTE, valamint `CASE` vagy ablakfüggvény.
